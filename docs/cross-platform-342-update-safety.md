# 3.141（342）Windows 与移动端更新保护

- Windows 安装器等待程序文件释放后再替换，重试临时文件占用，并保留上一版程序作为恢复副本。正常卸载不删除资料库。
- Windows 应用内更新助手在新版本验证完毕前保留旧程序；启动失败时先保护新包和旧包，再尝试恢复；状态文件兼容 UTF-8 BOM。
- 安装前触发草稿与同步完成检查，检查失败时不继续安装。Android 更新仍使用原应用签名和系统确认；Web App 更新继续先保存草稿并维持原浏览器存储。
- Windows 339 的旧更新器不能被远程替换，所以 342 的首次 Windows 升级使用手动安装包，不向旧客户端推送 342 自动安装；安装后的新版本可使用修复过的更新器。
- Android 可从 339 收到 342 更新；在旧版本安装之前应先保存输入。iPhone/iPad 从原有网址使用 Web App 342。Mac 保持 341。
- 程序恢复副本留在原安装目录旁边；资料库和书籍始终不在安装程序的删除范围内。

验证包括真实 Windows 测试机上的安装、已有程序覆盖、ZIP 更新、启动超时回滚和从 339 更新；Android 编译与签名校验；模拟浏览器中的手机／平板阅读及实际 339→342 离线草稿保留。实体设备兼容性需要在实际设备上继续验证。
