## 数据与退出

增量日志位于本机 notebook.json.wj-journal / drafts.json.wj-journal，与原 JSON 一起构成本机最新状态。完整备份会先落盘检查点，再导出普通兼容备份；不要只在程序运行时复制 notebook.json 作为完整备份。正常托盘退出会先保存草稿并完成检查点。崩溃后下一次启动重放校验过的日志；遇到不一致保留文件并报错，不猜测覆盖。此机制只用于 Windows 本地资料模式，未改云端同步内容格式。

## 验证边界

- 类型检查、原生数据事务/恢复、原同步回归和最终构建检查。
- Mac 上运行 Electron 并注入 Windows 应用分支：虚构 PDF、书架、笔记与草稿，未访问个人资料。报告明确标注 hostPlatform=darwin，不能用于推断 8 GB Windows 笔记本的实际帧率、耗时或内存。
- 实际 Windows 安装器执行、非系统磁盘安装、系统托盘、驱动/核显/独显、睡眠恢复与资源峰值，交付后在 Windows 验证。不宣称已经在真实 Windows 上测试。
- 中文字体本轮保留已有离线字体，不通过删字体或降低识别模型来换速度。永久 PDF 全文索引、GPU OCR 后端仍未实现。部分完整导入与同步操作仍需处理全量快照。

## 建议实机验证顺序

1. 旧版先导出完整备份，退出托盘中的问间；安装到原目录，确认仍能选择磁盘和文件夹。
2. 打开原有扫描 PDF，翻页、滚动并输入笔记；核对原批注、识别结果、页码及草稿。
3. 收起到托盘再恢复、完整退出重开，核对阅读位置和保存结果。
4. 默认关闭图形加速先体验一次；需要时在「设置 → 图形硬件加速」开启，从托盘退出后重开，对比同一 PDF。若开启后异常，关闭后再完整重启。
5. 检查原有坚果云同步与另一台设备上的笔记、书籍内容。发生问题时保留本机数据和日志，反馈「帮助 → 性能信息（本机）」及具体复现步骤，不发送账号密码。
