# Mac 335：交叉思考按空位收纳

日期：2026-10-20。显示版本 3.14（330.5），内部构建 335。

## 已确认的交互

- 同列来源中间有空位时，收起胶囊与展开卡片均利用这个空位，子树继续向右。
- 关联中心已有普通问题时，收起为窄而高的标记，贴在中间问题的右上侧，底部高于普通问题正中的子问题出口。
- 不直接按奇偶决定形状；检查来源列、中心位置和实际卡片占位。角落已被其他标记或卡片占用时回到横向间隙，避免叠放。
- 展开卡片仍在同一张画布中，交叉子树各有行列；仅扩大相邻间隔。收起恢复紧凑布局。
- 普通问题编号、来源 ID、原始笔记和关联记录不因布局改变。

## 线路

- 紫色关联使用直角括线，重复的共线线段合并后只画一次，避免多条曲线来回缠绕。
- 来源正上/正下且同列时采用短的竖向连接。
- 简短路径碰到卡片时，寻找边界绕行路径；不通过卡片内部画捷径。
- 灰色父子线优先显示。紫线与其交叉时留出断口，不加连接点，表达经过而非汇合。
- 点击交叉标记高亮实际来源与该交叉分支，不再把来源到核心问题的全部祖先路径一起染紫。
- 关闭的深层来源仍借所属交叉标记表示，展开后连接恢复到真实子问题。
