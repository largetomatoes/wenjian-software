# Mac 333：可编程插件框架

2026-10-20，用户授权先改 Mac。基于已安装的 332（3.14 / 330.2），下一本机构建 333（3.14 / 330.3）。Windows、Android、Web 不打包、不发布。保留已有声明式外部工具 v1。

## 目标

允许社区为自己的资料开发本地分析、替代问题图、编辑整理、归档/恢复/清除及导入导出插件。问间不内置 AI 服务或自动推导关系。开发者使用公开格式和虚构测试库，不取得用户私人资料。

## 实施表

1. **包和 SDK v2**：UTF-8 `.wenjian-plugin` JSON，HTML/CSS/JS 内嵌包、版本/兼容/权限/网络地址声明，保持 v1 兼容；大小限制、严格验证、示例和投稿文档。
2. **真正的运行隔离**：独立 Electron 沙箱窗口、独立非持久 session、无 Node、无任意 IPC；禁止直接网络、导航、弹窗、子框架、下载和系统权限。插件仅通过固定 SDK 调用宿主；主窗口私有请求头隔离内部 HTTP API，防止越权绕过。独立进程提高故障隔离，但不宣称绝对安全。
3. **按次授予范围**：启动时选择问题页或明确的卡片集/书籍范围；关闭窗口即撤销。引用范围外记录时只保留 ID，不泄露标题或正文。全库须明确选择，不自动跨页递归。
4. **只读和展示**：读取脱敏后的授权快照、问题图节点/层级/交叉边；插件可自由绘图。独立私密存储保存结果/布局；原始文件路径、同步密钥、OCR 整库不暴露。
5. **受事务保护的编辑**：新增问题/卡片/读书思考，修改授权正文，增加关联、调整页面位置；预览影响、原生确认、版本冲突拒绝、修订历史和时间。归档/恢复/永久清除使用原生资料模型，问题/交叉/书籍先仅归档；清除支持安全可解除引用的记录，既有原件限制保留并明确报错。宿主写入前保存可恢复私密快照；正常同步捕获增改删，不把同步状态暴露给插件。
6. **模型和网络**：本机服务和远端 HTTPS 分开授权、按包声明地址精确限制、禁止自动重定向/转向内部宿主端口、超时/大小/并发限制。无需申请远程网络即可连接指定本机模型。显示本地与联网权限。
7. **文件与高级扩展**：通过原生文件选择器读/写用户单独选择的文本文件；高级本地执行默认关闭，另行警示并由用户选择可执行程序，不接受插件提供路径或 shell。高级程序拥有操作系统赋予的能力，不能承诺继续受插件沙箱约束；限定单次运行时长与输出，窗口关闭终止任务。
8. **管理界面**：已安装插件可启动、查看权限、运行状态、停止、停用、卸载；停止全部和会话级安全模式；更新/停用/卸载立即关闭旧运行窗口，卸载不删除笔记；可以清除该插件独立设置。安装时明确新增权限。
9. **验证**：模型/包单测、越权和并发/过期令牌测试、虚构库 GUI 真实插件运行（图、修改确认、删除恢复、本机服务、无直连/无 Node）、v1/EPUB/关系图回归、类型与签名检查。
10. **交付**：本机工程记录、完整 Mac 包；用户正式库仅做备份核验，不用于破坏性插件测试。保留原演示版和旧版恢复包，正常退出后原位替换正式 Mac，不推 GitHub。

## 约束与验收

- 本轮实现可验证的扩展能力，不承诺“任意代码也能被精确限制权限”。高级本地执行的风险须在启用前准确说明。
- 结构调整通过页面位置模型保留原始归属；不开放随意覆盖全部 notebook JSON 的接口。
- 删除影响范围、引用处理与同步均由宿主负责。私密恢复副本仍保留历史数据，不声称永久清除会抹除所有旧备份和云服务历史。
- 不伪造市场插件；示例随源码提供、不默认安装。线上市场目录和发布需另行操作，本轮本机验收。
