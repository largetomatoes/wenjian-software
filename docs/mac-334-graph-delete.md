# Mac 334：交叉布局与万用删除

日期：2026-10-20。显示版本 3.14（330.4），内部构建 334。

此为已安装的历史记录。交叉布局随后按用户反馈继续调整，详见 [Mac 335 交叉布局](mac-335-cross-layout.md)；335 已经用户确认原位替换正式应用。

## 本轮范围

- 采用已确认的图片方案。普通问题列保留，交叉根节点在最右来源的下一列；来源用虚线汇合，交叉子问题向右分层。
- 同画布展开、收起；收起紧凑、展开仅增大相关间隔。移除悬停出现的“添加子问题”，详情页的添加入口保留。
- 提供默认关闭的宿主内置“万用删除”。第三方插件原有权限约束不因此放宽。
- 内容原处的删除入口，以及按所属位置分类的集中管理，两者均实现。
- 本轮仅安装正式 Mac。演示版不改，其他系统暂不打包，不发布 GitHub。

## 集中分类

1. 问题页：按页名选择，查找原问题、回答、交叉思考、后续思考、回复及关联。
2. 书籍与文献：读书或 Zotero、书名、章节，再筛选过程笔记、读书笔记、高亮和来源批注。共同笔记为同一 ID，不复制记录。
3. 卡片集：想法或问题、自定义标签。
4. 文稿：按稿名，管理正文记录、段落、引用和句子关联。
5. 分类与收纳：图书文件夹、Zotero 分类、标签与手动联系。
6. 历史与归档：所属位置、类型、时间和归档状态。

## 原处入口

- 问题图的普通节点、展开的交叉节点、收起的交叉胶囊、问题详情、问题页签。
- 卡片列表、卡片架、卡片详情、标签整理。
- 图书列表、文件夹抽屉、Zotero 分类、Zotero 批注。
- 阅读中点选 PDF/EPUB 原文高亮，分别处理同一处的高亮与过程笔记。
- 过程注解的悬停预览和详情、本书笔记、问题里的阅读笔记、回复与修订、文稿列表。

## 删除、恢复与兼容

- 确认窗口显示目标、受影响记录和问题页；可选仅移出某页，保留原记录与其他页面。
- 删除原问题包含其原始子问题，修复各页位置和引用，保留独立书籍笔记和文稿中的文字。
- 删除最后一页后留下一个新的空白问题页，其他资料保留。移除主页和同步中对固定 world ID 的旧假设。
- 版本、正文、关联变化要求重新核对；仅阅读进度变化可重新计算，不妨碍读书时删除标注。
- 单次令牌、超时、停用撤销、私密本机快照、差异回执和不覆盖后来修改的恢复。
- 删除 Zotero 文献或分类记录来源忽略状态，防止下一次联动自动复活；不删除 Zotero 原件。
- 书籍原文件与旧备份保留供恢复。删除默认根问题会提示旧版 Windows/手机需要升级后再同步。
- 不在正式资料上做破坏性测试，安装前备份和校验，正常退出后原位替换。
