本文件记录首轮独立试用。用户随后明确同意修复拖入后替换本机；最新范围与说明见 local-record-storage-2026-11-02.md。

开始：2026-11-01；验收：2026-11-02；基线：33b2b2c8f2ce4bb5f359e0a416a6f19b5b8ebf83（公开 344）。

## 边界

- 不替换 /Applications/问间.app，不读取或写入正式 profile、正式草稿、云连接和凭据。
- 不推送或发布、不升级 Windows/Android/Web。交付独立 bundle ID 与独立资料目录的 Mac 应用。
- 使用虚构 PDF/EPUB、问题、摘录及长文做测试。真实资料仅可由使用者主动通过完整备份导入副本。
- 普通高亮与带过程笔记的原文高亮独立配色；不改写旧批注的颜色。

## 设计约束

SQLite 是试用版的事实来源；JSON 是可移植导出/备份格式。确认成功的写入必须完成本地持久化；本地成功不代表云端成功。数据库事务中同时更新当前记录、恢复前像和待同步变更。重试携带同一操作 ID，操作不可执行两遍。

历史去重保留全部表述和时间；缓存与人工校对分开。导入旧 JSON 后逐记录比较规范化内容摘要，完成后才标记迁移成功。旧 JSON 和事务日志在导入时不得修改。备份必须包含草稿和书籍，并从一致性快照导出；还原后重新载入数据库。

试用阶段禁用共享云写入，保留 outbox 验证；不提前变更现有坚果云协议。待本机体验确认后，单独验证旧端兼容与增量云同步。

性能报告区分实测、目标和未覆盖场景；不得通过删历史、降 OCR 质量、静默吞保存错误或移除 Gatekeeper 规避问题。

## 试用范围与后续边界

- 本轮完成 SQLite 事实存储、按记录保存与冲突检查、历史内容去重、同事务恢复前像与 outbox、按页 OCR 载入和关键词索引。
- UI 保留当前笔记的完整表述和历史，尚未将所有历史面板改成服务端分页。归档、批量导入等兼容操作仍可能读取完整快照；日常高亮与正文保存不再走这条路径。
- 本轮不启用正式云同步或更改坚果云协议；outbox 已验证持久化，跨端发布需要另行验证旧端、离线端与冲突恢复。
- 性能数字区分 Node 存储基准与实际 Electron 功能验证，不能把数据库耗时当作完整 UI 响应时间。
- 没有替换正式应用、移动真实资料目录或推送 GitHub。
