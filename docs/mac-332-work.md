# Mac 332 本机改动

日期：2026-10-20。基于本机 331；仅 Mac，本轮不发布其他平台或 GitHub。

- EPUB：唯一的高亮绘制控制器，按 rendition/书籍/CFI 管理，避免 epub.js 同位置重复登记和未挂载章节清理留下的索引。保存记录保持不变；按章节挂载、翻页、重排恢复，高亮与过程笔记统一去重。测试往返章节、翻页、字号/窗口重排、退出重开、同位置高亮与注解。
- 关系图：收起时仅占胶囊位置，不为隐藏子树保留大块空白。展开某条交叉时，按完整子树撑开所在的那一处间隔；后续内容整体顺延，其他间隔保持原大小。收起恢复紧凑距离。父子向右分列、兄弟各占一行，交叉树不进入原问题的行槽。画布不因展开而自动平移/缩放。默认紫色胶囊与细虚线；胶囊本体仅高亮，每个交叉胶囊有明确的「展开」文字按钮，展开卡片有独立的「收起」文字按钮，在同一画布显示真实分支；收起不删除内容。交叉根及完整子树均处于预留的行间区域，多条树各占独立行区，不创建子树窗口或独立滚动区。深层子问题可独立关联，收起时标出确切来源编号，可主动展开来源。支持多路、跨页来源、交叉的子问题。操作不自动移动或缩放画布。普通问题仍全部展开。
- 关联选择：标题、行内空白、箭头只展开/收起；只有复选框改变选择。叶节点标题不自动勾选。不联动勾选上级；新增交叉保存精确来源 ID。交叉提示和常驻统计分区放置。
- 插件：设置内增加市场与已安装管理；第一版提供声明式外部工具接口、包格式、开发文档和投稿规则。保留在线目录/离线导入、兼容检查、启停/卸载；不捏造上架插件，不自动收集笔记或提供写入能力。卸载保留笔记。不内置第三方 AI 服务；外部工具由用户自己安装和主动调用。
- 验证：纯函数、TypeScript、隔离 Mac UI、构建准备产物；包含既有退出保存回归。本轮保持独立预览，用户确认画布交互前不替换正式应用。预览数据、草稿继续保留。后续替换须正常退出并备份最新资料、草稿和书库，同 bundle ID，保持桌面演示版。

## 交叉入口与实际点击补充

从问题编辑窗口发起交叉思考时，自动带入当前问题的精确 ID；从主界面发起仍由用户选两个及以上问题。未达到数量时按钮显示「再选 N 个问题」，标题未填写时说明原因。标题只为交叉思考命名，不充当来源。选中热区扩大到复选框周围，名称点击仍只展开下级。
