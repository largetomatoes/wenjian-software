# Mac 本机优化与拖入修复

2026-11-02。用户在独立试用后明确允许：修复向右拖入笔记板，再原位替换本机问间。本轮不发布其他平台。

## 修复

原来只有 `.paper-document` 接受摘录，标题区和滚动容器剩余空白不接受。现在整个正文编辑滚动区接收内部摘录，正文前后空白分别映射到开头和末尾；外部普通文本仍走原有文本编辑行为。EPUB 跨 iframe 指针拖动也使用相同的接收范围。

已在正式候选包验证 PDF、实际 OCR 文字、EPUB 的顶部与下部空白拖入；原有关键词、脚注、联系、历史、保存失败重试和输入回归通过。

## 正式包与试用包

- 正式 Mac 包使用 `recordStorage: true`，沿用原 bundle ID、资料目录、草稿、书库及同步连接。`recordStorage` 的运行时启用条件限于 darwin 本地资料库。
- `architectureTrial: true` 仅属于独立预览包，保留不同身份和独立目录，禁用共享云与正式更新。不能把预览包直接覆盖正式应用。
- 原同步协议继续使用完整同步 envelope；新本地记录事务不修改其历史。已通过离线的实际应用 API 互通检查，没有使用真实账号制造云请求。
- SQLite 为事实来源；原 JSON 为导入/导出快照。更新、完整备份、还原必须经过适配器，不能只复制旧 JSON 作为最新资料。
- 不支持通过直接覆盖旧二进制来任意切换存储引擎。需要回退时，先保存完整备份，并核对新旧资料。后续构建必须保留数据适配器与 package 配置，不能重新使用改造前的 main.js。

## 安装和恢复

本次正常退出后，先保护旧应用与最新资料，再在私有副本迁移并逐项比较；通过后原位替换。书籍原件没有搬移。恢复副本保留在本机 profile 的 upgrade-safeguards，包含原资料、草稿和原应用。

`scripts/install-local-records.cjs` 是本次安装脚本，包含特定旧包摘要保护，不是通用发行安装器。后续发行需要重新打包、签名清单并使用新的内部构建号，不能覆盖 GitHub 已发布的 344 安装包。

详细本机审计和验收证据在工作区 outputs/local-install、outputs/drag-fix，含用户资料的保护副本不得进入 Git 仓库。
