# 3.141（340）桌面阅读性能

本版仅发布 macOS 和 Windows。Android 与 iPhone/iPad Web App 继续使用 339。

- 桌面阅读进度增量接口接受连续阅读模式、相对位置与位置页码；仍使用本机事务日志、版本检查和检查点，确保异常退出后可以恢复。
- 桌面连续阅读的 OCR 缓存普通更新不再重新绘制 PDF 位图；高亮内容未变化的页面保留已有高亮索引。
- 自动 OCR 在用户停止操作后启动；Mac 复用阅读器的 OCR 引擎并保留空闲释放机制。不会在阅读过程中中断正在运行的识别。
- 保留手动 OCR、原文摘录、跨页坐标、扫描识别和撤销历史。优化不更改识别分辨率或语言数据。

验证包含桌面增量接口、崩溃恢复、旧数据兼容、跨页同步、模拟浏览器画布重绘，以及更新选择的跨平台回归；实际速度依赖文档和设备。
