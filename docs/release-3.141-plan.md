## 平台边界

- Windows 保留已验证的轻薄本性能策略，不能套用 Mac OCR/GPU 默认设置。
- 安卓沿用原 keystore、包名和本机存储；iPhone/iPad 沿用现有 Web App / IndexedDB 与同源 WebDAV 中转，不把 PWA 说成 App Store 应用。
- 万用删除默认关闭；原处按钮与六类管理页一致。删除前保留恢复副本，恢复不能覆盖后来的相关修改。书籍原件与旧备份保留。
- 插件平台声明按实际系统检查。桌面沙箱和本机程序能力不能照搬到移动浏览器；界面需明确当前支持范围，不展示无效操作。
- 不更改个人笔记内容，不将个人数据、账户、密码、密钥或虚构测试资料放入公开包。
- 仅模拟云账号测试；不能把构建或模拟浏览器检查说成 Windows 轻薄本、安卓手机、iOS Safari 实机验收。

## 发行说明原则

面向使用者简述：关系图交叉思考的新收纳与线路、阅读和 EPUB 高亮修复、插件与可恢复删除、各端体验统一。详细技术过程留在本工作表和源码文档，不堆在 GitHub 发布正文。
