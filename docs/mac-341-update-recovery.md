# 3.141（341）Mac 更新安全修复

部分用户在 340 更新后遇到应用包不完整。原因尚未完全确认，因此本版收紧更新和恢复流程，并暂时停用旧版 Mac 的自动更新发现。

- 新应用报告启动后，更新助手再次核验应用包身份和完整性；只有助手完成核验后才报告更新成功。
- 更新助手不再递归删除新旧应用包。成功后保留旧应用作为恢复副本；失败时先验证旧包，再将失败包移开并恢复旧包。
- 341 使用手动安装包发布。旧版自带的更新器无法接收它，避免在修复前再次执行原地替换。
- 新版本可在以后的更新中使用新的保护逻辑，但旧版本不应自动升级到本版。
- Android、Windows、iPhone 和 iPad 不包含在本次修复中。

验证：隔离的虚构包测试覆盖正常启动、启动超时、应用包损坏及回滚；使用隐藏测试模式运行真实 Mac 应用和 Electron 更新助手，确认新旧应用、图标与独立笔记文件完整。
