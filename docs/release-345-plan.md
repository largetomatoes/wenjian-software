## 功能与实现

- 桌面端启用后台 SQLite 记录事务：普通修改按变化记录保存，OCR 按页载入，输入先在编辑器中即时响应。
- 首次跨版迁移保留旧文件、日志与草稿，暂存迁移并完整核对后启用；已有 SQLite 不重新导入旧 JSON。
- 后续更新保护从当前数据库导出一致性资料和草稿，避免只备份陈旧 JSON。保留更新签名、SHA256、启动核对及失败恢复。若回退后的旧程序或外部工具改写旧资料文件，新版停止载入并保留两份资料，避免静默忽略后写的内容；正常启动只核对文件元数据，不再解析整个旧 JSON。
- 各端使用同一阅读编辑器、高亮配色与笔记板交互。手机继续原生分块保存，Web 继续 IndexedDB；不把桌面存储文件强行搬进手机。
- 修复 PDF/OCR/EPUB 摘录拖入笔记板正文上下空白处；保留引用定位与修改历史。
- 更新界面说明可跳跃升级，失败时提供手动覆盖入口；Mac 对 App Translocation 和不可写目录明确提示，不绕过 Gatekeeper。
- Windows 保留原字体、GPU 默认关闭、托盘、安装磁盘选择；可从已核验的同版本已发布 Electron 二进制离线重建，所有应用代码与资源重新生成。
