# 正文内摘录笔记板：实现与验收

> 后续完成：正文内关键词笔记板已安装至本机，见 [最终完成记录](reading-board-keywords-2026-10-29.md)。本文保留此前阶段的历史记录。

日期：2026-10-28。本轮仅做独立 Mac 预览，未替换正式应用，未推送或发布其他平台。

## 用户确认

- 名称为「笔记板」。
- 自己的思路是一篇连续正文；摘录落在文中具体位置。
- 正文中可以出现独立引用【1】，以及【2】—【3】这样的联系。
- 点联系在附近展开自己的说明，关闭后保留原文本位置。
- 默认布局以用户截图为准：阅读约 60%、笔记板约 40%，保留拖动分隔线。

## 实现

1. 阅读顶栏改名，进入笔记板时收起书架。使用相对宽度，避免按固定像素挤压不同尺寸的窗口。
2. 保留原生 textarea 的输入、输入法和文本选择；镜像文字层绘制可点击的文中摘录与联系。宽度变化时测量镜像，保持行排对应。
3. PDF 原生选文拖动携带带版本的内部来源包，保存文字、原始文字、书名、章节、页码和几何位置。连续 PDF 使用自己的分段选文采集器。
4. 拖入点通过镜像 DOM 计算 UTF-16 位置，并吸附到既有引用边界。外部普通文字不会被猜测成某本书的引用。
5. EPUB 保留书页实际 Range 的完整文字；元素边界转换为等价文本边界后生成精确 CFI，避免内容被缩成第一个字。已选文字再次拖动时使用软件内的跨 frame 指针会话，绕开本次实测会卡住的 macOS 原生跨框拖放；完成、取消、切换书籍会释放会话。
6. 相邻引用建立联系时只整理标记间的连接符，不挪动作者的句子。非相邻引用保持位置，通过标记查看同组联系。
7. 联系说明是覆盖在正文附近的临时展开层，不挤走句子。多处来源、修改时间、原有注解和缺失来源快照继续保留；修改复用完整修订和草稿机制。
8. 新笔记使用 square 标记格式；既有纸面结构保留旧标记兼容，不强制重写旧数据。
