# Mac 3.141（339）：PDF 连续阅读

本次先完成 Mac，保留原来的单页模式。读书书架、Zotero PDF 和对照阅读共用阅读器；各 PDF 的阅读模式、所在页及页内位置保存在该书的进度中。旧记录没有这些字段时按单页处理。

连续模式为每页保留独立尺寸、文字层和标注，视口附近加载画布，远处保留占位。页面旋转、缩放、窗口动画和阅读栏尺寸变化后按原阅读位置定位。已有文字层优先；扫描页在阅读停止片刻后识别，识别结果按书、页和旋转写入现有 OCR 缓存队列。旧缓存可以先显示，待新结果完成后更新。两栏共用 OCR 排队，像素预处理在后台工作线程运行。

跨页选文依然是一条高亮、过程笔记或读书思考；`pdfSegments` 保存各页原文和坐标。已有 `sourceLocation` 保持第一页，旧笔记继续使用原格式。批注版 PDF 导出使用各页坐标。旧版本可保留和同步这些数据，但不了解 `pdfSegments`，因此不保证能在所有涉及的页面显示跨页高亮；跨平台更新时需适配此字段。

验证：`tests/test-mac339-continuous.cjs` 使用虚构 PDF 检查单页切换、真实鼠标跨页选文、两页导出、旧 OCR 缓存、真实 OCR、位置/缩放/旋转、120 页按需加载、Zotero 批注、对照共同笔记以及完整重启。`tests/test-pdf-crosspage-sync.mjs` 检查数据同步往返，`tests/test-shared-ocr-slot.mjs` 检查排队取消。`tests/test-mac337-reader-stability.cjs` 回归单页 OCR 和滚动稳定性。

本次构建只用于 Mac 本地验证；其他平台和公开发布需另行同步和验收。
