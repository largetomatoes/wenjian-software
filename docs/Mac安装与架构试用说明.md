# Mac 独立架构试用

本包与正式「问间」是两个独立应用。不要覆盖「应用程序」中的正式问间；在交付目录双击「问间·架构试用.app」即可。初始内容全部是虚构资料，可自行导入书籍。资料保存在同一交付目录的「试用资料」，退出后保留，方便检验重开与恢复。

应用不连接正式坚果云、OSS、Zotero 和正式更新。SQLite 只管理试用资料；导出完整备份仍使用问间原有可移植格式。导入真实备份意味着在此创建独立副本，之后的修改不会返回正式资料库。试用内容如需保留，请先导出完整备份。

正式 Mac ZIP 安装建议：解压后，通过 Finder 将「问间.app」本身移入「应用程序」，再从该位置打开，不要在下载压缩包或系统临时隔离位置中执行应用内更新。若系统提示开发者无法验证，请在 macOS「系统设置 → 隐私与安全性」核对应用后选择允许打开；不要关闭 Gatekeeper 或删除 quarantine 属性。

更新器若检测到 App Translocation 或不可写安装目录，会在保护资料、启动安装和写入安装状态前停止，并说明手动覆盖步骤。自动更新仍保留原有清单签名、SHA256 校验、用户数据保护和失败回滚。

删除试用：先正常退出「问间·架构试用」，将整个交付目录删除即可。它不会卸载或修改正式问间。请只在确认不需要试用内容后删除「试用资料」。
