# Mac 本机修复：3.14（330.1），内部构建 331

日期：2026-10-20。基于公开构建 330，仅制作和替换本机 Mac。本轮不发布 GitHub、不替换演示应用，不构建 Windows、Android 或 Web。

## 范围与行为

1. 阅读、保存过程笔记或读书笔记后，点击右上角关闭：关闭前先保存草稿、等候笔记提交并核实阅读进度；失败时保留阅读窗口及原草稿。阅读页关闭时不再动画显示已经释放的空白 PDF/EPUB 页面。清理等待绘制的高亮与原文范围，将焦点恢复到书库按钮，使用 preventScroll；重新测量关系图有效尺寸，保留平移和缩放。复测包括批注预览显示时关闭、窗口缩放、Esc 和结束对照阅读。
2. 交叉问题按当前幕布的位置组织在主问题下，不再放在独立的全局“交叉思考”树中。外页来源只显示其所属问题页与完整路径，不拉入本页变成并列主问题。保留交叉问题的后续子问题。
3. 编号是位置的显示投影：每个上级下使用 X1、X2，后续问题如 X1.1；汇总页中的位置自动带上级编号。原始全局 order、UUID、引用、时间和历史文字均不改写。旧记录缺少 pageId 时，优先采用其唯一原始位置。汇总页调整不修改原页，也不覆盖原交叉记录的 pageId。
4. 点击交叉问题仅高亮来源、所属主问题路径与连线，不移动位置、不改变缩放、不自动弹出编辑窗口。预览中提供“打开这条思考”，编辑、继续添加思考的能力保留。
5. 关联选择保持主问题层级；来源路径按需展开。删除重复的已选列表，给主列表分配可伸缩空间和常驻滚动条；滚轮、触控板和键盘可滚动。图内预览的滚动不再被背景关系图当成平移手势，滚动及查找不会清空已选关联。
6. 文稿、搜索、关联标签和导出使用对应问题页的编号，避免把显示编号与旧全局顺序混用。

## 检查依据与边界

- 已确认旧版把关联树中的交叉问题集中在单独分组；图中只有来源连线，缺少位置所属上级连线。画布 wheel 处理无条件 preventDefault，导致图内可滚动预览的滚动被转成平移。
- 未在隔离环境稳定复现用户资料中报告的持续白屏，因此不将某个未证实的原因写成确定根因。此次修正关闭的保存顺序、焦点恢复、离场动画、尺寸测量与高亮清理，并覆盖用户指出的“做笔记后右上角退出”路径。
- 不删除任何用户记录，不改云端内容，不调整同步连接或个人偏好。本轮无数据格式升级。

## 替换流程

1. 预备份本机笔记、草稿与日志；通过原生退出协议等候所有草稿和写入队列保存并完成检查点，不强制退出。
2. 退出后再次备份最新笔记和草稿，完整书库使用 APFS 文件克隆以节省空间；保存 SHA-256 清单，核对记录数与书籍文件。
3. 同一路径原位替换 `/Applications/问间.app`，核对 bundle ID，重新启动，检查本机接口版本、资料数目、书籍和草稿校验。若启动失败，保留原应用供回退。
4. 保留源码提交和检查记录，清除本轮临时构建目录，避免堆积大体积文件。
